# Registry catalogue (AIDCF-014 §17)

The registries required by AIDCF-014 §17 (TDS-REQ-057) that are not published elsewhere in `registries/`. Every file carries the common columns `code`, `label`, `definition`, `semanticOwner`, `version`, `status`, `replacedBy`, followed by the registry-specific columns of §17.

All files are generated by `registries/tools/build_catalogue.py` and must not be edited by hand. Run it with `--check` in CI: it exits non-zero if regenerating would change any file.

```
python3 registries/tools/build_catalogue.py           # regenerate
python3 registries/tools/build_catalogue.py --check   # verify
```

## Index

`registry-index.csv` lists all twenty §17 registries, including those maintained by other tools (domains, control families, controls, critical gates and the controlled vocabularies). For each one it gives the published path, the owner, whether the file carries the common columns, the columns still missing, the row count and the sources. The index is computed from the published file headers, so it shows the remaining gap as it stands.

## Conventions

- Format: UTF-8, LF line endings, RFC 4180 quoting, one header row, rows sorted by `code` in natural order. Cells holding several values separate them with `|`.
- An empty cell means no source defines the value. Values are never filled in by inference.
- `version` is the MDM data release the row was generated for (`RELEASE` in `schemas/tools/aidcf_model.py`, currently 1.3).
- `status` uses the record lifecycle of AIDCF-014 §11A.1. No catalogue row is approved yet, so rows are `CANDIDATE`. In `deprecated-terms.csv` a term with a replacement is `SUPERSEDED` (with `replacedBy` set) and a term with none is `RETIRED`.
- `evidence-classes.csv`, `unknown-types.csv`, `unknown-severity.csv`, `decision-states.csv` and `assessment-methods.csv` are projections of the matching files in `registries/vocabularies/`, extended with the §17 columns. If a projection and its vocabulary file differ, the vocabulary file governs. Regenerate the catalogue to resolve the difference.
- `external-mappings.csv` also carries the `confidence` column of the AIDCF-019 crosswalks.
