# Registries

Canonical AIDCF-007A baseline registries as CSV: 15 domains, 90 control families, 360 controls, critical gates and assessment states.

These are copied from the AIDCF-015 v1.2 package (`implementation/aidcf-015-v1.2/registries/`), except that `controls/controls.csv` carries the control titles and normative requirements from the 007A workbook. The v1.2 package's copy has placeholder titles and requirement text and is left unchanged as released. The authoritative workbook is `standards/aidcf-007a/registry/AIDCF-007A_Canonical_Master_Control_Registry_15-90-360_v1.0.xlsx`. If the two ever differ, the workbook governs.
