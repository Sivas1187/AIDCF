# Core Conceptual Model

[AIDCF-002 Core Conceptual Model v1.0](AIDCF-002_Core_Conceptual_Model_v1.0.md), dated 2026-10-10, status Draft for controlled review.

AIDCF-002 is second in the AIDCF precedence order, after the Manifesto. It defines the normative keywords (*shall*, *should*, *may*), the canonical 16-step assurance chain and its mapping to ISO/IEC/IEEE 15026-2 and GSN, the core concepts and their definitions (including "material" and where UNKNOWN is permitted), the artifact identifier scheme, and the controlled vocabularies published as CSV in `registries/vocabularies/`.
