# Schemas

Machine-readable AIDCF v1.2 schemas, copied from `implementation/aidcf-015-v1.2/`:

- `json-schema/`: JSON Schemas for control assessments, evidence, gates, scores and decisions
- `jsonld/`: JSON-LD context
- `rdf/`: RDF/Turtle core vocabulary
- `shacl/`: SHACL shapes
- `owl/`: reserved for a future OWL ontology
