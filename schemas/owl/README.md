# AIDCF OWL ontology

`aidcf-core-1.3.ttl` is the OWL 2 ontology of AIDCF-016 MDM 1.3, generated by `../tools/build_schemas.py`.

| Item | Value |
|---|---|
| Ontology IRI | `https://w3id.org/aidcf/ontology` |
| Version IRI | `https://w3id.org/aidcf/ontology/1.3` |
| Namespace | `https://w3id.org/aidcf/ontology#` (prefix `aidcf:`) |
| Resolution | w3id registration pending; IRIs do not yet resolve |
| Status | Draft for controlled review (2026-10-10) |

Contents:

- The 48 AIDCF-014 section 7 classes with their definitions and chain step, grouped under abstract superclasses; the reference classes Location, PartyEntity and Component; the supporting classes IACS, IACSZone, Conduit, SecurityLevel, FoundationalRequirement and Assertion, annotated `aidcf:registrationStatus` as pending AIDCF-014 registration; and the auxiliary class RelationshipRecord.
- The 41 AIDCF-014 section 9 relationships as object properties with domain and range unions, cardinality annotations, qualifier annotations and declared inverses (`owl:inverseOf`). Inverses are for navigation only: records never assert them (AIDCF-016 rule MDM-R11, enforced in SHACL).
- Datatype, structural and list properties of the class profiles.
- One SKOS concept scheme per controlled vocabulary, with concept IRIs `https://w3id.org/aidcf/vocab/<scheme>/<CODE>` and legacy aliases as `skos:hiddenLabel`.

OWL semantics are open-world. Cardinality, mandatory links and business rules are validated with the SHACL shapes in `../shacl/` under closed-world assumptions (AIDCF-014 TDS-REQ-052), and no inference is used to produce approval, support, conformity, gate or decision states (TDS-REQ-051).
