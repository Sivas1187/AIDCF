# Code of Conduct

AIDCF adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct for everyone participating in issues, pull requests, reviews, discussions and other project spaces.

In addition, participants in AIDCF review are expected to:

- challenge ideas, evidence and methods, not people;
- disclose conflicts of interest relevant to a review or contribution;
- never post confidential facility, customer or security-sensitive information (see [SECURITY.md](SECURITY.md));
- respect third-party intellectual property, including standards text.

## Reporting

Report unacceptable behaviour privately to the repository maintainer through GitHub, not in a public issue. A dedicated reporting address will be published here once configured.

Reports will be reviewed promptly and handled confidentially. Enforcement follows the Contributor Covenant's Enforcement Guidelines.
