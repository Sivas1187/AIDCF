# Executive thesis

An AIDCF assessment is a controlled chain from decision question to capability, outcomes, boundary, dependencies, controls, failure paths, evidence, critical gates, independent review and bounded decision. The chain is never strengthened by presentation, averaging or automation.

## Lifecycle

Initiate -\> Profile -\> Scope -\> Tailor -\> Plan -\> Collect -\> Validate -\> Assess -\> Analyse -\> Gate -\> Find -\> Review -\> Decide -\> Report -\> Reassess
