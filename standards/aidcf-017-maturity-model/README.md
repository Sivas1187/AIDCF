# AIDCF-017 Capability Assurance Maturity Model

[AIDCF-017 Capability Assurance Maturity Model v1.0](AIDCF-017_Capability_Assurance_Maturity_Model_v1.0.md), dated 2026-10-10, status Draft for controlled review.

AIDCF-017 describes how mature an organisation's capability to produce and sustain AIDCF assurance is. A maturity level is not an Assurance Decision, a score band or a certification, and it never overrides a critical gate.
