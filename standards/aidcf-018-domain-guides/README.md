# AIDCF-018 Domain Guides

One guide per AIDCF-007A control domain, version 1.0, dated 2026-10-10, status Draft for controlled review.

Each guide explains what the domain covers in an AI data centre, its families and controls, the failure modes and dependencies that matter, how its controls feed the critical gates, what good evidence looks like, assessment methods with testing-safety limits, typical UNKNOWNs and the related external standards. The controls themselves are normative only in the AIDCF-007A registry; a guide never changes a control.
